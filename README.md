# HearCast Finder

HearCast Finder is an Android-focused Flutter app concept for finding public locations that may support Auracast or Bluetooth LE Audio broadcasts.

This repository starts on August 12, 2026 and will be developed incrementally. The Day 1 version is intentionally small: it only contains the basic Flutter shell, a simple home screen, and a few hard-coded example location ideas.

## Current Day 1 Scope

- Minimal Flutter app entry point
- Simple Material theme
- Home screen with project purpose
- Static candidate location list
- Basic smoke test

## Not Implemented Yet

- Firebase authentication
- Firestore storage
- Google Maps
- Native Android Bluetooth scanning
- Reports, reviews, favorites, owner tools, or admin tools
